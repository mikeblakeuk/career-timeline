# Career Timeline

Interactive, single-file HTML career timeline. Open `index.html` directly in a browser, or visit the GitHub Pages site.

## Features
- Horizontal time-proportional axis from 1995 to present
- Role bars with company-coloured fills derived from logos
- Hover any role to see full details (bullets, clients, skills) below the timeline
- Click for a full modal
- Mouse-wheel zoom (anchored at cursor)
- Collision-resolved milestone labels, project sub-bars, and role cards
- Toggle certifications/training on or off

## Local preview
Just open `index.html` in any modern browser. No build step.

## Hosting on GitHub Pages
Settings → Pages → Build from branch → `main` / `/ (root)`.
